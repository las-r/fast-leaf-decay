# Fast Leaf Decay
Exactly what it says on the tin. Makes leaves decay pretty much instantly. Available as a datapack and fully supported by all the major mod loaders.

## FAQ
**Q:** Mod support?\
**A:** As of v1.1.0, [Biomes O' Plenty](https://modrinth.com/mod/biomes-o-plenty) and [Terrestria](https://modrinth.com/mod/terrestria) are supported!

**Q:** What do you mean by "major mod loaders"?\
**A:** Fabric, Forge, NeoForge, and Quilt.

**Q:** Any dependencies?\
**A:** If you're on Fabric, the [Fabric API](https://modrinth.com/mod/fabric-api) is a dependency.
