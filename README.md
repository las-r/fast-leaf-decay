# Fast Leaf Decay
Exactly what it says on the tin. Makes leaves decay pretty much instantly. Available as a datapack and fully supported by pretty much all the major mod loaders.

## FAQ
**Q:** Mod support?\
**A:** Coming soon! As of v1.0.0, only vanilla is supported, but I'm working on it.

**Q:** What do you mean by "major mod loaders"?\
**A:** Fabric, Forge, NeoForge, and Quilt.
