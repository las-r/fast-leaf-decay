# Fast Leaf Decay
Exactly what it says on the tin. Makes leaves decay pretty much instantly. Available as a datapack and fully supported by all the major mod loaders.

## FAQ
**Q:** Mod support?\
**A:** Most mods that add leaf types should be supported, as long as they properly add tags and predicates.

**Q:** What do you mean by "major mod loaders"?\
**A:** Fabric, Forge, NeoForge, and Quilt.

**Q:** Any mod dependencies?\
**A:** For Forge or NeoForge, none. For Fabric or Quilt, you need the [Fabric API](https://modrinth.com/mod/fabric-api).
